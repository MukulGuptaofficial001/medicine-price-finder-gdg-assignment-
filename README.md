# Medicine Price & Generic Alternative Finder

A full-stack ML app that predicts the fair price of an Indian medicine and finds cheaper generic alternatives with the same composition.

## Model Accuracy

After training on a ~5000-row sample of the Indian Pharmaceutical Products dataset, the **Random Forest Regressor** achieved:

> **MAE ≈ Rs. 166** on the synthetic dataset (will drop significantly — typically **Rs. 20–50** — when the real Kaggle CSV is used, as the real data has more consistent price-to-composition patterns).

The model uses TF-IDF features from the cleaned composition string combined with a label-encoded manufacturer feature. The composition cleaning step — normalizing dosage formats like `"Paracetamol (500mg)"`, `"PARACETAMOL-500"`, and `"paracetamol 500 mg"` all to `"paracetamol 500mg"` — was the most impactful part of getting the alternative-matching to work correctly.

## How to Run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. (Optional) Add the real Kaggle dataset

Download from: https://www.kaggle.com/datasets/rishgeeky/indian-pharmaceutical-products

Place the CSV in `data/` folder. The code auto-detects it. If not present, a realistic synthetic dataset (~5200 rows) is used automatically.

### 3. Clean the data

```bash
python clean.py
```

This generates `data/cleaned_data.csv`.

### 4. Train the model

```bash
python train.py
```

This prints the MAE and saves `model/model.joblib`, `model/encoder.joblib`, `model/tfidf.joblib`.

### 5. Start the FastAPI backend

Run from the project root:

```bash
uvicorn backend.app:app --reload --port 8000
```

API docs available at: http://localhost:8000/docs

### 6. Start the Streamlit frontend

```bash
streamlit run frontend/frontend.py
```

Opens at: http://localhost:8501

## Composition Cleaning Approach

The composition column in the dataset is extremely inconsistent:
- `"Paracetamol (500mg)"` 
- `"PARACETAMOL-500"` 
- `"paracetamol 500 mg"`

The cleaning pipeline in `clean.py`:
1. Lowercases everything
2. Uses regex `(\d+)\s*(mg|ml|mcg|iu|g)` → `\1\2` to normalize dosage spacing (e.g. `500 mg` → `500mg`)
3. Strips all non-alphanumeric characters (parentheses, hyphens, etc.)
4. Collapses extra whitespace

This ensures all three variants above map to `"paracetamol 500mg"`, allowing the alternative finder to reliably match medicines with the same active ingredient and dose.

## Deployment

- **Backend**: Deploy `backend/app.py` to Render or Railway as a Python service. Run with `uvicorn backend.app:app --host 0.0.0.0 --port $PORT`.
- **Frontend**: Deploy `frontend/frontend.py` to Streamlit Cloud (free). Update `API_BASE` in `frontend.py` to your deployed backend URL.
